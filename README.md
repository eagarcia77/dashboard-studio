# Dashboard Studio

Dashboard Studio convierte uno o varios archivos en dashboards dinámicos directamente en el navegador.

## Formatos compatibles
- Excel: `.xlsx`, `.xls`
- CSV: `.csv`
- Word: `.docx`
- PowerPoint: `.pptx`
- PDF: `.pdf`

## Funciones
- Carga múltiple por selector o drag & drop.
- Procesamiento local en el navegador.
- Detección de conjuntos de datos por archivo.
- Combinación automática de datasets con las mismas columnas.
- KPI, tabla exploratoria y gráficas dinámicas.
- Barras, líneas, dona, pastel, radar y área polar.
- Exportación a PNG y PDF.
- Diseño responsive para computadora, tableta y móvil.

## GitHub Pages
Después de publicar los archivos, vaya a **Settings > Pages > Build and deployment**, seleccione **Deploy from a branch**, `main` y `/ (root)`.

La aplicación usa librerías JavaScript desde CDN, por lo que requiere conexión a Internet para cargar esas dependencias.
